# License decision before public release

The intended direction is open source plus an optional hosted service. The owner
has not selected a license. This repository therefore uses `UNLICENSED` and
`private: true` as temporary bootstrap metadata and has no public-license grant.
Do not describe this preview as an already open-source release.

Before publication, the owner must decide the desired redistribution and hosting
terms, review license compatibility of added dependencies, choose a contributor
inbound policy, add the actual license text, and update package metadata.
Do not silently substitute a source-available license for a request for open source.
This file is a decision boundary, not legal advice or license text.
