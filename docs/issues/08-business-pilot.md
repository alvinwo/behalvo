# Business workspace pilot with one vertical

Local issue draft; not yet created on GitHub.

Milestone: M3
Area: Product / Security
Risk: High

## Goal

Validate shared-kernel usefulness with actual solo-business operators, without leaking personal memory.

## Acceptance criteria

- [ ] Recruit a small set of real operators and choose one appointment/follow-up workflow.
- [ ] Enforce workspace membership and customer-specific context disclosure at query time.
- [ ] Preserve owner-versus-customer identity boundaries across email, IM and phone.
- [ ] Measure completed bookings, qualified opportunities, human intervention and service cost; do not label every inquiry revenue.
- [ ] Test calendar race conditions, holds, cancellations, travel buffers and provider limitations.
- [ ] Keep personal dogfooding and business market validation as separate feedback loops.
