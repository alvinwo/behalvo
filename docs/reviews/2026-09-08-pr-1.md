## Confirmed findings resolved

| Finding | Resolution |
| --- | --- |
| Retrying an older pending input could omit that input from model context while binding facts to its source. | Pin the exact scoped owner record, including beyond the recent history tail; fail closed if it cannot fit. |
| Completed redelivery called the model before rejecting the handled record. | Reject before model invocation or work linking. |
| CLI startup failed in paths containing spaces. | Compare the entrypoint using `pathToFileURL`. |
| API-key entry lacked a secret reader, allowing a pasted key to become subsequent chat. | Implement hidden secret input and verify it stays out of prompts and artifacts. |
| Canceled partial OAuth codes, or secrets retained in readline's kill ring, could become later chat. | Discard canceled partial input and isolate editor state across authentication prompts; verify Ctrl+U/Ctrl+Y cannot recover credentials. |
| Concurrent first Pi logins created separate stores and lost a successful credential write. | Share the initialization promise and credential store; permit retry after failed initialization. |
